# Security Policy

## Reporting a vulnerability

Datakraften takes security seriously. If you discover a security issue, please do NOT open a public issue.

Instead, report it privately by emailing the maintainers or opening a GitHub Security Advisory at:

https://github.com/sagathelab/datakraften/security/advisories/new

## What to include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response

We will acknowledge receipt within 48 hours and work on a fix. We'll keep you informed throughout the process.

## Scope

The following are in scope:
- The `dk` CLI binary and source code
- The `install.sh` bootstrap script
- The website (datakraften.no)

The following are out of scope:
- Third-party tools installed by Datakraften (Homebrew, fnm, uv, etc.)
- Browser extensions or unrelated tools
