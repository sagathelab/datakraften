Privacy Policy

Datakraften does not collect personal data through the CLI by default.

The website (datakraften.no) may collect standard technical server logs, such as IP address, timestamp, browser user agent, and requested URL, for security and operational purposes.

Datakraften does not sell personal data.

If optional telemetry is introduced in the future, it will be documented clearly and designed to be opt-in.
