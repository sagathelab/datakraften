Codex CLI

OpenAI's command-line tool for code generation

What is it?

OpenAI Codex CLI is a command-line tool for code generation. It uses AI models to generate, explain, and modify code directly in your terminal.

Basic Usage

Generate code from a prompt

$ codex "write a python function that sorts a list"

Install git hooks

$ codex --install-hooks

Help

$ codex --help

Tips

💡 Run codex --install-hooks to set up git hooks for AI-assisted commit messages and code review.

💡 Requires an OpenAI API key set via the OPENAI_API_KEY environment variable.
