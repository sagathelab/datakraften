gh copilot

GitHub Copilot in your terminal

What is it?

GitHub Copilot CLI brings Copilot to your terminal — get command suggestions, explanations, and translations from natural language without leaving the command line.

Basic Usage

Suggest a command

$ gh copilot suggest "list all modified files"

Explain a command

$ gh copilot explain "git rebase -i HEAD~3"

What the shell?

$ gh copilot what-the-shell

Interactive mode

$ gh copilot

Tips

💡 Run gh copilot without arguments to enter interactive mode for back-and-forth prompting.

💡 Uses GPT models under the hood — great for learning git and shell commands you haven't memorized yet.

💡 You must be logged in with gh auth login and have a Copilot subscription to use this feature.
