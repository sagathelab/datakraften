.NET SDK

Cross-platform SDK for building C#, F#, and VB applications

What is it?

The .NET SDK is a cross-platform development framework for building a wide range of applications — web, mobile, desktop, cloud, and IoT — using C#, F#, or Visual Basic. The bootstrapper installs the latest .NET SDK via the Microsoft package repository.

Basic Usage

Create a new project

$ dotnet new console -n MyApp
$ dotnet new webapi -n MyApi
$ dotnet new mvc -n MyWebApp

List available templates

$ dotnet new list

Build and run

$ dotnet build
$ dotnet run

Run tests

$ dotnet test

Publish for deployment

$ dotnet publish -c Release -o ./publish

Check installed SDKs

$ dotnet --list-sdks
$ dotnet --list-runtimes

Tips

💡 DOTNET_ROOT is set in your fish config. The SDK is installed to /usr/share/dotnet.

💡 Use dotnet new list to browse all available project templates — there are dozens including console, web, class library, and more.

💡 Add --help to any dotnet command for detailed usage info, e.g. dotnet new --help.
