btm

Cross-platform graphical system monitor

What is it?

bottom (btm) is a cross-platform graphical system monitor for the terminal. It displays CPU, memory, disk, network, processes, and temperatures in a rich TUI interface.

Basic Usage

Start bottom

$ btm

Navigate

Arrow keys  — move between widgets and processes
?           — show help
1-9         — toggle individual widgets on/off
Ctrl+C      — quit

Basic mode

$ btm -c

Tips

💡 Use btm --mem_as_value to display memory as numeric values instead of a percentage.

💡 Configuration lives in ~/.config/bottom/bottom.toml — customize colors, widgets, and layout.

💡 Run btm -t for the default widget arrangement, useful after customizing to reset the layout.
