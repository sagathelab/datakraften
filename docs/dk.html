dk CLI

Bootstrap, configure, and diagnose your developer workstation

dk init

Generate your Datakraften configuration file. Detects your operating system, package manager, and preferred shell, then writes ~/.config/datakraften/config.yaml.

$ dk init

What it does

  • Detects platform (WSL, Linux, macOS)
  • Identifies native package manager (apt, dnf, yum, pacman, brew)
  • Generates a YAML config with default profile
  • Safe to re-run — won't overwrite existing config unless forced

dk apply

Install everything defined in your active profile. Idempotent — safe to run repeatedly.

$ dk apply
$ dk apply --dry-run    # Preview without installing

What it installs

  • System packages — via apt, dnf, yum, pacman, or brew
  • Homebrew — installs brew if missing, then brew packages
  • Runtimes — Node.js via fnm, Python via uv, .NET SDK
  • Shell — Fish shell config with managed blocks
  • Skips already-installed tools. Uses sudo only for system packages.

Dry-run mode

Use --dry-run to see what would be installed without making changes:

$ dk apply --dry-run
[dry-run] would install system packages: git curl build-essential ...
[dry-run] would install brew packages: fish starship atuin fzf ...
[dry-run] would install Node.js via fnm (LTS)

dk doctor

Run comprehensive diagnostics on your system. Checks every category that dk apply configures.

$ dk doctor
$ dk doctor --json     # Machine-readable output

Check categories

  • System — distribution, kernel, WSL version, systemd
  • Tools — git, curl, build tools, Homebrew
  • Runtimes — Node.js, Python, .NET SDK
  • Editors — VS Code, Zed, Cursor detection
  • Docker — daemon status, socket access, WSL integration
  • Shell — Fish config, Starship prompt, Atuin, FZF

dk status

Quick overview of installed tools and their versions. Detects what's available on your PATH and reports version info.

.NET:      8.0.x

dk profile

Manage Datakraften profiles — predefined sets of tools for different developer types.

List available profiles

$ dk profile list

Available profiles

  • minimal — just system tools and git
  • default — balanced setup for most developers
  • ai — AI development toolchain
  • dotnet — .NET ecosystem
  • frontend — web development
  • platform — platform engineering

Switch profile

$ dk profile use ai
$ dk apply             # Re-run apply with the new profile

Tip: Profile definitions live in ~/.config/datakraften/profiles/. You can create custom profiles too.

Global flags

All commands support these flags:

  • --dry-run — preview changes without executing
  • --json — structured output for scripting
